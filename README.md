# GOGOCar—動態環境下的智慧路徑規劃系統

本專案構建了一個模擬二維物理矩陣空間，結合強化學習與主動式安全防禦機制，讓無人車在動態多障礙環境中自主尋找最短路徑並安全規避碰撞。

## 1.核心技術：
- Python / NumPy / Matplotlib / Q-Learning
## 2.系統設計特點：
- 二維動作空間設計：具備模擬物理車頭朝向狀態('N','E','S','W')，定義離散動作為前進（F）、原地轉向（L/R）。
- 兩階段訓練流程：第一階段於無人靜態地圖進行3000輪Q-Table迭代訓練；第二階段凍結最優策略並引入多個動態隨機慣性移動之行人進行路徑驗證。
- AEB自動緊急煞車系統：開發雙重危險偵測機制，同時檢查「當前重疊碰撞」與依據行人的移動向量預測「下一秒預期碰撞」。AEB具備最高優先權優先攔截決策，當觸發時強制原地駐車，直至危險解除後恢復尋路。
## 3.實測結果：
- 系統在面臨單次或多步連續軌跡衝突時，皆能準確觸發煞車防禦，並以最優步數順利抵達終點。
